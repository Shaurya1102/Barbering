# Architectural Decisions

Major decisions are recorded as ADR files.

Current accepted decisions: - `ADR-001-postgresql.md` --- PostgreSQL
primary database - `ADR-002-central-auth.md` --- Spring Security central
auth with HTTP-only cookie sessions

Do not ask the user to reconsider an accepted decision unless new
evidence creates a genuine architectural problem.

Create a new ADR when changing an accepted architectural decision.
